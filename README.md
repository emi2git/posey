# Posey

Website + camera trainer: reads the webcam and checks exercise form in real time with
MediaPipe PoseLandmarker (runs in the browser, loaded from a CDN). Plain HTML/CSS/JS, no framework, no build.

## Site layout

| URL | File | |
|---|---|---|
| `/` | `index.html` | landing: hero only (headline, stick-man, Start) |
| `/exercises` | `exercises.html` | one card per registry entry (generated by `site.js`) |
| `/workout?exercise=<id>` | `workout.html` + `app.js` | the camera trainer |
| `/how-it-works` | `how-it-works.html` | friendly version of HOW-IT-WORKS.md |
| `/about` | `about.html` | about + privacy (`/about#privacy`) |
| anything else | `404.html` | |

Shared: `site.css` (tokens, light/dark from the system), `site.js` (mobile nav, exercise cards, hero/404 stick-man),
`workout.css` (trainer only). Header/footer markup is repeated in each page; edit all six when changing nav.
Assets: `favicon.svg`, `icon-192/512.png`, `apple-touch-icon.png`, `og-image.png`, `site.webmanifest`, `_headers`.
Links are absolute clean URLs (`/about`); Cloudflare Pages maps them to `.html`, and `serve.sh` does the same locally.

## Run

```sh
./serve.sh            # then open http://localhost:8000 (PORT=8123 ./serve.sh for another port)
```

The camera only works on `localhost` or HTTPS. On a phone, open it through an HTTPS
tunnel (e.g. `cloudflared tunnel --url http://localhost:8000`).

## Deploy

Cloudflare Pages project `posey` (live at https://posey-c55.pages.dev). Copy only the site files to a temp folder, then deploy:

```sh
D=$(mktemp -d) && cp -R *.html *.css *.js *.png favicon.svg site.webmanifest _headers exercises "$D"/ \
  && npx wrangler pages deploy "$D" --project-name posey --branch main --commit-dirty=true; rm -rf "$D"
```

## Squat (sample exercise)

Stand side-on, full body in frame. Uses the more visible side.

- Depth: knee angle (hip-knee-ankle). A rep starts below 140° and ends standing above 160°. It counts only if the
  knee stayed below 100° for 3 frames in a row AND no correction fired during the rep.
- Turning back up before depth (knee opens 15° past its lowest point): "Go lower" at once; that rep is failed.
- Torso lean (shoulder-hip vs. vertical) above 45°: "Chest up"; that rep is failed too.

## Jumping Jacks

Face the camera, whole body in frame. Arms = lower wrist height (0 at the shoulder line, 1 at the top of the head);
feet = ankle spread / shoulder width.

- A rep starts when the arms rise past -0.2 or the feet open past 1.4x, and ends when arms are back down (< -0.5)
  with feet together (< 1.3x). It counts only if arms >= 1 and feet >= 1.5x held together for 3 frames in a row
  AND no correction fired during the rep.
- Coming back in before the top (arms drop 0.3 or feet close 0.3 from their peak): "Arms higher" and/or
  "Feet wider" at once; that rep is failed.

## Rep counting (both exercises)

- Metrics go through a 5-frame trimmed moving average (drop min and max) inside each rep counter, so one noisy
  frame can't cross a threshold. app.js passes each frame's raw metrics plus its corrections to `update()`.
- A failed rep stays failed until the start position, then everything resets.
- Tests: `node tests/reps.test.mjs` (synthetic landmark sequences: shallow, noisy dip, form error then deep, clean).

## Demo and voice

- A looping stick-man (bottom right of the trainer; also on the exercise cards and the home hero) shows the correct movement; each exercise defines its own `demo` keyframes.
- Voice (Web Speech API): corrections are spoken immediately and cancel stale speech. Each clean rep is counted
  out loud ("One", "Two"…, digits after twenty). Praise ("Good job", "Keep it up"…) only every 5th rep or, rarely
  (10%, at least 3 reps apart), at random; never the same phrase twice in a row. Same phrase is not repeated within 2 s.
  Unlocked on the first click; speaker button mutes.
- Voice picker (header): "Auto" picks the best English voice: names with Premium/Enhanced/Natural/Neural, then Google
  English voices (Chrome; these are online voices), then good macOS voices (Samantha, Ava, Zoe, Allison…). The choice is
  saved in localStorage. Rate 1.02, pitch 1.
- Better voices on macOS: System Settings → Accessibility → Spoken Content → System Voice → Manage Voices, download
  e.g. "Ava (Premium)" or "Zoe (Premium)", then reload the page.

## Add an exercise

Create `exercises/<name>.js` exporting `{ id, name, view, instructions, check(landmarks, aspect), describe(metrics), createRepCounter(), demo }`
(plus `summary` and `checks` for the cards; see `exercises/squat.js`, `exercises/jumping-jacks.js` for a front view with custom demo `limbs`; helpers in `exercises/geometry.js`) and add it to `exercises/index.js`. It then shows up on the home page, `/exercises`, `/how-it-works` and in the trainer picker.
